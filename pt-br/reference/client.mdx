## WaClient {#waclient}

```ts
new WaClient(options: WaClientOptions, logger?: Logger)
```

Veja [Configuração](/pt-br/concepts/configuration) para cada opção.

### Ciclo de vida e estado {#lifecycle--state}

| Membro | Assinatura | Descrição |
| --- | --- | --- |
| `connect` | `() => Promise<void>` | Abre o socket; conduz o pareamento na primeira execução. |
| `disconnect` | `() => Promise<void>` | Fecha de forma graciosa, mantendo as credenciais. |
| `logout` | `(reason?) => Promise<void>` | Desvincula o dispositivo no servidor. |
| `getState` | `() => WaAuthState` | Estado atual de auth/conexão. |
| `getCredentials` | `() => WaAuthCredentials \| null` | Credenciais atuais, se pareado. |
| `getClockSkewMs` | `() => number \| null` | Estimativa de desvio do relógio do servidor. |

### Emissor de eventos {#event-emitter}

| Membro | Assinatura |
| --- | --- |
| `on` | `(event, listener) => this` |
| `once` | `(event, listener) => this` |
| `off` | `(event, listener) => this` |

Os três são tipados contra [`WaClientEventMap`](/pt-br/concepts/events).
