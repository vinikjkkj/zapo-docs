## Perfil {#profile}

O `client.profile` ([`WaProfileCoordinator`](/pt-br/reference/client#profile)) lê e grava campos de perfil da sua conta e os consulta para terceiros.

### Foto de perfil {#profile-picture}

```ts
import { readFile } from 'node:fs/promises'

// Ler a foto de alguém (ou a sua)
const pic = await client.profile.getProfilePicture(jid)

// Definir a sua
await client.profile.setProfilePicture(await readFile('./avatar.jpg'))

// Removê-la
await client.profile.deleteProfilePicture()
```

### Recado / texto de status {#about--status-text}

```ts
const about = await client.profile.getStatus(jid)
await client.profile.setStatus('Available')
```

### Push name {#push-name}

O `pushName` é o nome de exibição que os contatos veem para a sua conta em chats e listas de participantes de grupo. A mudança é enfileirada como uma mutação de app-state e se propaga na próxima mensagem que você enviar — não há broadcast imediato.

```ts
await client.profile.setPushName('Alice')
```

Passar string vazia restaura o nome para o padrão de fingerprint do dispositivo.

### Modo temporário padrão {#default-disappearing-mode}

O `setDisappearingMode` define a duração padrão de modo temporário aplicada a **novos** chats 1:1 iniciados por você. Chats existentes mantêm a configuração por chat.

```ts
// 0 desliga, 86400 = 24h, 604800 = 7d, 7776000 = 90d
await client.profile.setDisappearingMode(604_800)

// Desligar
await client.profile.setDisappearingMode(0)
```

Para mensagens temporárias por grupo, veja [Grupos → mensagens temporárias](/pt-br/guides/groups#disappearing-messages).

### Consultas em lote {#batched-lookups}

```ts
const profiles = await client.profile.getProfiles([jidA, jidB])
const usernames = await client.profile.getUsernames([jidA, jidB])
const modes = await client.profile.getDisappearingMode([jidA, jidB])
```

### Checar se um número está no WhatsApp {#check-if-a-number-is-on-whatsapp}

Resolva números de telefone para o [LID](/pt-br/concepts/identities) e descubra se cada um está registrado no WhatsApp:

```ts
const results = await client.profile.getLidsByPhoneNumbers(['+55 11 99999-9999'])
// → [{ phoneJid: '5511999999999@s.whatsapp.net', lidJid: '…@lid', exists: true }]

for (const r of results) {
  if (r.exists) console.log(r.phoneJid, 'está no WhatsApp →', r.lidJid)
}
```

### Nomes de usuário {#usernames}

```ts
const mine = await client.profile.getOwnUsername()
const available = await client.profile.checkUsernameAvailability('myhandle')

await client.profile.setUsername({ username: 'myhandle' })
await client.profile.deleteUsername()
```

## Privacidade {#privacy}

O `client.privacy` ([`WaPrivacyCoordinator`](/pt-br/reference/client#privacy)) controla as categorias de privacidade e a lista de bloqueios.

### Configurações de privacidade {#privacy-settings}

```ts
const settings = await client.privacy.getPrivacySettings()

// Atualizar uma única configuração
await client.privacy.setPrivacySetting('last', 'contacts')
```

Os nomes e valores das configurações vêm das constantes `WA_PRIVACY_*` (`last`, `online`, `profile`, `status`, `readreceipts`, `groupadd`, …). Veja a [referência de JID e constantes](/pt-br/reference/jid-helpers#constants).

### Lista de bloqueios {#blocklist}

```ts
const { jids } = await client.privacy.getBlocklist()

await client.privacy.blockUser(jid)
await client.privacy.unblockUser(jid)
```

### Listas de exceção {#disallowed-lists}

Para configurações escopadas a uma lista específica de contatos (por exemplo, "compartilhar com todos, exceto…"):

```ts
const result = await client.privacy.getDisallowedList(category)
```

## Business {#business}

O `client.business` ([`WaBusinessCoordinator`](/pt-br/reference/client#business)) lê perfis business e nomes verificados, e gerencia o seu próprio perfil business.

<Badge color="purple" icon="briefcase">Conta business</Badge> — necessária para **editar** seu próprio perfil ou foto de capa; os métodos de leitura funcionam para qualquer conta.

```ts
// Ler perfis business (em lote)
const profiles = await client.business.getBusinessProfile([jidA, jidB])

// Consultas de nome verificado
const name = await client.business.getVerifiedName(jid)
const names = await client.business.getVerifiedNames([jidA, jidB])

// Editar seu próprio perfil business
await client.business.editBusinessProfile({ /* WaEditBusinessProfileInput */ })

// Foto de capa
await client.business.updateCoverPhoto(mediaSource)
await client.business.deleteCoverPhoto(coverId)
```

### Business hours tipados {#typed-business-hours}

`WaBusinessHoursDay` e `WaBusinessHoursMode` são aliases de union (`'sun' | 'mon' | …`, `'open_24h' | 'specific_hours' | 'appointment_only'`). Os valores também estão congelados em `WA_BUSINESS_HOURS_DAYS` e `WA_BUSINESS_HOURS_MODES`. Passar um `mode` desconhecido para `editBusinessProfile` agora lança um erro local claro em vez de o servidor responder `406 not-acceptable` — dias fechados continuam sendo expressos **omitindo-os** da `config`, não por um mode dedicado.

```ts
import { WA_BUSINESS_HOURS_DAYS, WA_BUSINESS_HOURS_MODES } from 'zapo-js'

await client.business.editBusinessProfile({
  businessHours: {
    timezone: 'America/Sao_Paulo',
    config: [
      {
        dayOfWeek: WA_BUSINESS_HOURS_DAYS.MON,
        mode: WA_BUSINESS_HOURS_MODES.SPECIFIC_HOURS,
        openTime: 540,  // minutos desde meia-noite; 540 = 09:00
        closeTime: 1080 // 18:00
      },
      { dayOfWeek: WA_BUSINESS_HOURS_DAYS.SAT, mode: WA_BUSINESS_HOURS_MODES.OPEN_24H }
      // dom é fechado — omitir
    ]
  }
})
```
